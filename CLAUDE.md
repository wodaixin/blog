## Project Overview

Personal blog site built with **Hugo** and the **Hugo Theme Stack** starter. The theme is vendored under `_vendor/` and referenced as an indirect dependency in `go.mod`.

- Published at: https://wodaixin.github.io/blog/
- Primary language: Chinese (zh), with CJK support enabled
- Author: wodaixin

---

## Common Commands

```bash
# Local dev server with live reload (port 1313)
hugo server

# Build for production (outputs to /public)
hugo

# Build with drafts included
hugo server --buildDrafts
```

---

## Directory Structure

```
config/_default/     Hugo configuration (params.toml, config.toml, menu.toml, etc.)
content/              Site content organized by type
  post/               Blog posts (e.g. content/post/ai/index.md)
  page/               Static pages (archives, links, search)
  categories/         Auto-generated category pages
layouts/              Custom layout overrides (Hugo merges with theme)
  partials/
    footer/custom.html  Custom WeChat contact modal (JavaScript + CSS inline)
static/               Static assets (images, fonts — served as-is)
resources/            Hugo auto-generated asset cache
public/               Built site output (gitignored, generated by hugo)
```

---

## Configuration

- **Site config**: [config/_default/config.toml](config/_default/config.toml) — baseurl, languageCode, hasCJKLanguage, pagination
- **Params**: [config/_default/params.toml](config/_default/params.toml) — sidebar, article, widgets, color scheme
- **Menu**: [config/_default/menu.toml](config/_default/menu.toml) — main nav and social links (GitHub, Email, WeChat)
- **i18n**: [config/_default/zh.toml](config/_default/zh.toml) — Chinese UI strings

---

## Customizations

- **WeChat modal**: Inline JS/CSS in [layouts/partials/footer/custom.html](layouts/partials/footer/custom.html) — triggered by any anchor with `#wechat` in the href. Shows a QR code modal with fade-in animation.
- The sidebar subtitle and author tagline are set via `params.toml` under `[sidebar]`.
- Comments are wired to Disqus (`disqusShortname` is empty in config — enable by setting it).
